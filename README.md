# 🐼 游在成都 - 十大热门景点美食攻略

一个精美的成都旅游攻略单页网站，展示成都十大热门景点和必吃美食的详细攻略。

## 🌐 在线预览

[https://18906660980.github.io/trip/](https://18906660980.github.io/trip/)

## ✨ 功能特色

- 🎨 精美的视觉设计，成都红主题配色
- 📱 完整响应式适配（桌面/平板/手机）
- 🔄 滚动渐入动画效果
- 🏷️ 10 大热门景点详细攻略（地址/门票/游玩时长）
- 🍜 10 种必吃美食推荐（餐厅/人均/辣度）
- 📋 交通/住宿/季节/注意事项实用攻略
- 🧭 固定导航栏 + 平滑滚动锚点
- 🖼️ 图片懒加载优化性能

## 📁 项目结构

```
trip/
├── index.html          # 主页面
├── css/style.css       # 全局样式 + 响应式
├── js/main.js          # 交互逻辑
├── images/             # 本地图片（预留）
└── README.md
```

## 🚀 本地运行

直接在浏览器中打开 `index.html` 即可预览，无需任何构建工具。

## 🛠️ 技术栈

- 纯 HTML5 + CSS3 + Vanilla JavaScript
- Google Fonts（Noto Sans SC）
- Intersection Observer API（滚动动画）
- CSS Grid + Flexbox 布局
- GitHub Pages 部署
